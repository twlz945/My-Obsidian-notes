# 本库约定

本文件描述目标 Obsidian 库的既有结构，用于给新笔记选择目录、标签和链接。若用户指向了别的库，请先扫描该库再调整，不要直接套用。

## 库根目录

默认库：`C:\Users\twlz9\Documents\Obsidian Vault`（含 `.obsidian`，以此判定库根）。
可在调用脚本时用 `-Vault` 覆盖；用户指定其它库时以用户为准。

## 归档路由

根据关键词判断最贴近的目录，**优先放进已有目录，不要新建顶层目录**：

| 关键词类型 | 目标目录 |
| ---------- | -------- |
| 编程语言、框架、设计模式、依赖注入等 | `知识积累/编程/` |
| Godot | `知识积累/编程/Godot/` |
| 学习路线、教程、入门文档 | `知识积累/编程/教程/` |
| TCP/UDP/Socket/HTTP、Web 框架后端 | `知识积累/编程/网络/` |
| Markdown、Obsidian、双链、编辑技巧 | `知识积累/编辑/` |
| ESP32、FreeRTOS、GPIO、嵌入式 | `esp32/` 下对应子目录 |
| Turing Complete、指令集、CPU 架构 | `turing complete/` 下对应子目录 |
| 游戏开发方法、规划 | `游戏开发/规划/` |
| 具体项目 | `project/<项目名>/` |
| 日记、随笔、个人记录 | `杂记/` 或 `杂记/日记/` |
| 当天日期日志 | `2026/<MM>/<DD>.md` |

没有合适目录时，选择最接近的现有目录，或用 `知识积累/编程/` 作为编程类兜底。确实需要新目录时，先向用户确认。

## 命名与写作习惯

- 文件名即标题，用简洁的中文或中英混合，例如 `依赖注入.md`、`FastAPI.md`、`Socket 入门文档.md`。
- 避免 `未命名.md`、`未命名 1.md` 之类的名字；库中已有此类残留，不要模仿。
- 正文多为中文，使用二级/三级标题、表格、引用块。
- 库内已有笔记大多**没有** YAML 属性，仅有少量使用 `tags:`。新笔记按本技能规范加上属性即可，不影响兼容。
- 已有标签（优先复用）：`编程`、`编程技巧`、`网络编程`、`后端开发`、`Web开发`、`API开发`、`面向对象`、`计算机网络`、`操作系统`、`分布式系统`、`数据结构`、`教程`、`Python`、`Socket`、`TCP`、`UDP`、`FastAPI`、`Godot` 等。
