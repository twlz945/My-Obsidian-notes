`room = max(0, self.capacity - self.input_buf.get(item, 0))`
还有这种用法？
`self.capacity`机器缓存上限，`self.input_buf.get(item, 0)` 好像是返回已有物品的数量，没有就返回 0
`self.capacity - self.input_buf.get(item, 0) < 0` 说明还有空位

```python
n = min(qty, room) # 这段返回填进去了多少
if n:
    self.input_buf[item] = self.input_buf.get(item, 0) + n # n为0就不用改了
return n # 多余的返回去
```
