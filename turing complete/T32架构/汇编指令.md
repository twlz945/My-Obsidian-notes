# Symphony 汇编指令参考

本文档整理了 Symphony 架构的寄存器定义与全部指令集。

## 寄存器

Symphony 架构提供了 16 个 32 位寄存器，每个寄存器都有对应的二进制编码。

| 寄存器名    | 编码 (二进制) | 描述                  |
| :------ | :------- | :------------------ |
| `zr`    | `0000`   | 零寄存器，始终为 0          |
| `r1`    | `0001`   | 通用寄存器 1             |
| `r2`    | `0010`   | 通用寄存器 2             |
| `r3`    | `0011`   | 通用寄存器 3             |
| `r4`    | `0100`   | 通用寄存器 4             |
| `r5`    | `0101`   | 通用寄存器 5             |
| `r6`    | `0110`   | 通用寄存器 6             |
| `r7`    | `0111`   | 通用寄存器 7             |
| `r8`    | `1000`   | 通用寄存器 8             |
| `r9`    | `1001`   | 通用寄存器 9             |
| `r10`   | `1010`   | 通用寄存器 10            |
| `r11`   | `1011`   | 通用寄存器 11            |
| `r12`   | `1100`   | 通用寄存器 12            |
| `r13`   | `1101`   | 通用寄存器 13            |
| `sp`    | `1110`   | 栈指针寄存器              |
| `flags` | `1111`   | 标志寄存器（由 `cmp` 指令更新） |

## 指令集

指令按功能分类，每个指令包含助记符、语法、操作码格式和描述。

### 1. 数据传送与 I/O

| 指令         | 语法                  | 操作码 (32位)                             | 描述                               |
| :--------- | :------------------ | :------------------------------------ | :------------------------------- |
| `nop`      | `nop`               | `00000000 00000000 00000000 00000000` | 不执行任何操作。                         |
| `in`       | `in %a`             | `00000001 aaaa0000 00000000 00000000` | 从标准输入设备读入一个值到寄存器 `%a`。           |
| `out`      | `out %a`            | `00000010 00000000 0000aaaa 00000000` | 将寄存器 `%a` 的值发送到标准输出设备。           |
| `out`      | `out %a:U16`        | `00010010 00000000 aaaaaaaa aaaaaaaa` | 将 16 位立即数 `%a` 发送到标准输出设备。        |
| `keyboard` | `keyboard %a`       | `00000011 aaaa0000 00000000 00000000` | 读取一个键盘输入值并将其存入寄存器 `%a`。          |
| `screen`   | `screen %a, %b`     | `00000100 0000aaaa 0000bbbb 00000000` | 将寄存器 `%b` 的值写入显示屏的选项寄存器 `%a`。    |
| `screen`   | `screen %a, %b:U16` | `00010100 0000aaaa bbbbbbbb bbbbbbbb` | 将 16 位立即数 `%b` 写入显示屏的选项寄存器 `%a`。 |
| `time_0`   | `time_0 %a`         | `00000101 aaaa0000 00000000 00000000` | 将系统时间的低 32 位数值写入寄存器 `%a`。        |
| `time_1`   | `time_1 %a`         | `00000110 aaaa0000 00000000 00000000` | 将系统时间的高 32 位数值写入寄存器 `%a`。        |
| `counter`  | `counter %a`        | `00000111 aaaa0000 00000000 00000000` | 将程序计数器的值写入寄存器 `%a`。              |

### 2. 运算指令

#### 2.1 三操作数（寄存器-寄存器）

| 指令 | 语法 | 操作码 (32位) | 描述 |
| :--- | :--- | :--- | :--- |
| `nand` | `nand %a, %b, %c` | `00100000 aaaabbbb 0000cccc 00000000` | `%a = %b NAND %c` |
| `or` | `or %a, %b, %c` | `00100001 aaaabbbb 0000cccc 00000000` | `%a = %b OR %c` |
| `and` | `and %a, %b, %c` | `00100010 aaaabbbb 0000cccc 00000000` | `%a = %b AND %c` |
| `nor` | `nor %a, %b, %c` | `00100011 aaaabbbb 0000cccc 00000000` | `%a = %b NOR %c` |
| `add` | `add %a, %b, %c` | `00100100 aaaabbbb 0000cccc 00000000` | `%a = %b + %c` |
| `sub` | `sub %a, %b, %c` | `00100101 aaaabbbb 0000cccc 00000000` | `%a = %b - %c` |
| `xor` | `xor %a, %b, %c` | `00100110 aaaabbbb 0000cccc 00000000` | `%a = %b XOR %c` |
| `lsl` | `lsl %a, %b, %c` | `00100111 aaaabbbb 0000cccc 00000000` | `%a = %b << %c` (逻辑左移) |
| `lsr` | `lsr %a, %b, %c` | `00101000 aaaabbbb 0000cccc 00000000` | `%a = %b >> %c` (逻辑右移) |
| `asr` | `asr %a, %b, %c` | `00101001 aaaabbbb 0000cccc 00000000` | `%a = %b >> %c` (算术右移) |
| `cmp` | `cmp %a, %b` | `00101010 1111aaaa 0000bbbb 00000000` | 比较 `%a` 和 `%b`，结果存入 `flags`。 |

### 3. 控制流指令

| 指令 | 语法 | 操作码 (32位) | 描述 |
| :--- | :--- | :--- | :--- |
| `jmp` | `jmp %a` | `01001000 00001111 0000aaaa 00000000` | 无条件跳转到寄存器 `%a` 指定的地址。 |
| `jmp` | `jmp %a:U16` | `01011000 00001111 aaaaaaaa aaaaaaaa` | 无条件跳转到地址 `%a`。 |
| `je` | `je %a:U16` | `01010001 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a == b`，则跳转到 `%a`。 |
| `jne` | `jne %a:U16` | `01011001 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a != b`，则跳转到 `%a`。 |
| `jb` | `jb %a:U16` | `01010010 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a < b` (无符号)，则跳转到 `%a`。 |
| `jae` | `jae %a:U16` | `01011010 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a >= b` (无符号)，则跳转到 `%a`。 |
| `jbe` | `jbe %a:U16` | `01010011 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a <= b` (无符号)，则跳转到 `%a`。 |
| `ja` | `ja %a:U16` | `01011011 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a > b` (无符号)，则跳转到 `%a`。 |
| `jl` | `jl %a:U16` | `01010100 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a < b` (有符号)，则跳转到 `%a`。 |
| `jge` | `jge %a:U16` | `01011100 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a >= b` (有符号)，则跳转到 `%a`。 |
| `jle` | `jle %a:U16` | `01010101 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a <= b` (有符号)，则跳转到 `%a`。 |
| `jg` | `jg %a:U16` | `01011101 00001111 aaaaaaaa aaaaaaaa` | 如果 `flags` 显示 `a > b` (有符号)，则跳转到 `%a`。 |

### 4. 内存与外存访问

#### 4.1 加载 (Load)

| 指令 | 语法 | 操作码 (32位) | 描述 |
| :--- | :--- | :--- | :--- |
| `load_8` | `load_8 %dest, [%adr]` | `01100000 dddd0000 0000aaaa 00000000` | 从主内存 `%adr` 读取 8 位到 `%dest`。 |
| `load_8` | `load_8 %dest, [%adr:U16]` | `01110000 dddd0000 aaaaaaaa aaaaaaaa` | 从主内存地址 `%adr` 读取 8 位到 `%dest`。 |
| `load_16` | `load_16 %dest, [%adr]` | `01100001 dddd0000 0000aaaa 00000000` | 从主内存 `%adr` 读取 16 位到 `%dest`。 |
| `load_16` | `load_16 %dest, [%adr:U16]` | `01110001 dddd0000 aaaaaaaa aaaaaaaa` | 从主内存地址 `%adr` 读取 16 位到 `%dest`。 |
| `load_32` | `load_32 %dest, [%adr]` | `01100010 dddd0000 0000aaaa 00000000` | 从主内存 `%adr` 读取 32 位到 `%dest`。 |
| `load_32` | `load_32 %dest, [%adr:U16]` | `01110010 dddd0000 aaaaaaaa aaaaaaaa` | 从主内存地址 `%adr` 读取 32 位到 `%dest`。 |
| `pload` | `pload %dest, [%adr]` | `01100011 dddd0000 0000aaaa 00000000` | 从外存 `%adr` 读取 32 位到 `%dest`。 |
| `pload` | `pload %dest, [%adr:U16]` | `01110011 dddd0000 aaaaaaaa aaaaaaaa` | 从外存地址 `%adr` 读取 32 位到 `%dest`。 |

#### 4.2 存储 (Store)

| 指令 | 语法 | 操作码 (32位) | 描述 |
| :--- | :--- | :--- | :--- |
| `store_8` | `store_8 [%adr], %value` | `01100100 0000vvvv 0000aaaa 00000000` | 将 `%value` 低 8 位写入主内存 `%adr`。 |
| `store_8` | `store_8 [%adr:U16], %value` | `01110100 0000vvvv aaaaaaaa aaaaaaaa` | 将 `%value` 低 8 位写入主内存地址 `%adr`。 |
| `store_16` | `store_16 [%adr], %value` | `01100101 0000vvvv 0000aaaa 00000000` | 将 `%value` 低 16 位写入主内存 `%adr`。 |
| `store_16` | `store_16 [%adr:U16], %value` | `01110101 0000vvvv aaaaaaaa aaaaaaaa` | 将 `%value` 低 16 位写入主内存地址 `%adr`。 |
| `store_32` | `store_32 [%adr], %value` | `01100110 0000vvvv 0000aaaa 00000000` | 将 `%value` 写入主内存 `%adr`。 |
| `store_32` | `store_32 [%adr:U16], %value` | `01110110 0000vvvv aaaaaaaa aaaaaaaa` | 将 `%value` 写入主内存地址 `%adr`。 |
| `pstore` | `pstore [%adr], %value` | `01100111 0000vvvv 0000aaaa 00000000` | 将 `%value` 写入外存 `%adr`。 |
| `pstore` | `pstore [%adr:U16], %value` | `01110111 0000vvvv aaaaaaaa aaaaaaaa` | 将 `%value` 写入外存地址 `%adr`。 |

---

**格式说明：**

- `%a`, `%b`, `%c`, `%dest`, `%adr`, `%value` 表示寄存器，编码见寄存器表。
- `%a:U16` 表示一个 16 位立即数。
- `[%adr]` 表示间接寻址，即以 `%adr` 中的值为内存地址。
- `[%adr:U16]` 表示直接寻址，即以 16 位立即数为内存地址。
- 操作码中的 `aaaa`, `bbbb`, `cccc`, `dddd`, `vvvv` 是对应寄存器的 4 位二进制编码。
- `flags` 寄存器由 `cmp` 指令设置，用于条件跳转。
