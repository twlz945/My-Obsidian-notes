# TUI 常用符号

终端界面靠字符绘制边框、进度、状态和图标。现代终端对 UTF-8 支持普遍良好，但仍建议为关键字符准备 ASCII 回退（见文末）。

> 提示：下列符号的显示宽度受字体和终端影响，等宽字体（如 Cascadia Code、JetBrains Mono、Fira Code）效果最稳定。

## 制表符（画边框/表格）

| 用途  | 符号                      | 说明        | 码位       |
| --- | ----------------------- | --------- | -------- |
| 细线  | `│ ─ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼` | 单线边框，最常用  | U+2502 等 |
| 粗线  | `┃ ━ ┏ ┓ ┗ ┛ ┣ ┫ ┳ ┻ ╋` | 强调边框      | U+2503 等 |
| 混合线 | `║ ═ ╔ ╗ ╚ ╝ ╠ ╣ ╦ ╩ ╬` | 双线 + 单线混合 | U+2551 等 |
| 双线  | `╎ ╏ ╭ ╮ ╰ ╯`           | 圆角/虚线边框   | U+256D 等 |
| 缺角线 | `╴ ╵ ╶ ╷ ╸ ╹ ╺ ╻`       | 半截线，连接用   | U+2574 等 |
|     |                         |           |          |

圆角边框在 TUI 里常写作：

```text
╭──────────╮
│  Hello   │
╰──────────╯
```

## 方块元素（进度条/柱状图）

| 符号 | 名称 | 常见用途 | 码位 |
| --- | --- | --- | --- |
| `█` | Full block | 进度条已完成部分 | U+2588 |
| `▓` `▒` `░` | Shade blocks | 渐变、占用率、拖尾 | U+2593–2591 |
| `▏ ▎ ▍ ▌ ▋ ▊ ▉` | Left blocks | 高精度进度条（1/8 步进） | U+258F–U+2589 |
| `▀` `▄` | Upper/Lower half | 半高块、像素画 | U+2580 / U+2584 |
| `▖ ▗ ▘ ▝ ▙ ▚ ▛ ▜ ▟` | Quadrants | 迷你图表、二维码风格 | U+2596–U+259F |

进度条示例：

```text
下载中 [████████████░░░░░░░░] 60%
```

## 箭头与指示符

| 符号 | 含义 | 码位 |
| --- | --- | --- |
| `← → ↑ ↓` | 四向箭头 | U+2190–2193 |
| `↔ ↕ ⇄ ⇅` | 双向箭头 | U+2194–2195, U+21C4–21C5 |
| `▲ ▼ ◀ ▶` | 实心三角，折叠/展开、菜单光标 | U+25B2–25B6 |
| `△ ▽ ◁ ▷` | 空心三角 | U+25B3–25B7 |
| `‹ › « »` | 翻页/切换 | U+2039–203A, U+00AB–BB |
| `➜ ➤ →` | 提示、Next 按钮 | U+279C / U+27A4 |

树形结构（文件树、目录）：

```text
├── src
│   ├── main.py
│   └── utils.py
└── README.md
```

## 图标字体（Nerd Font）

`󰁕 󰄬 󰉋 󰊢 󰇄` 一类图标属于 Nerd Font 私有区（PUA，U+E000–F8FF），只有装了 Nerd Font 才显示，否则是方框/空白。**不要**在需要分发的 TUI 里硬编码，除非明确要求用户安装字体。

## 使用注意

- **宽度**：emoji、CJK、部分图标是双宽字符，`len()` 与终端显示宽度不一致。计算列宽用 `wcwidth`（Python）或 East Asian Width 属性。
- **组合字符**：带变体选择符（U+FE0F）的 emoji 可能占 2 列且渲染不稳，TUI 中尽量少用。
- **兼容性回退**：检测到 `LANG`/`TERM` 不含 UTF-8 或 `NO_COLOR`/`TERM=dumb` 时降级：

```python
UNICODE = True  # 根据环境检测

BOX = dict(tl="╭", tr="╮", bl="╰", br="╯", h="─", v="│") if UNICODE else \
      dict(tl="+", tr="+", bl="+", br="+", h="-", v="|")

CHECK = "✓" if UNICODE else "v"
CROSS = "✗" if UNICODE else "x"
```

- **对齐**：用等宽字体，制表符一律按字符宽度补齐，避免行尾多余空格导致边框错位。
- **颜色**：符号本身不带颜色，靠 ANSI SGR 序列着色，见 [[ANSI 转义序列]]。
