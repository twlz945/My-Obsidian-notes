# Python软件开发进阶阶段学习规划表（6-18个月）

## 一、数据结构与算法

### 1.1 线性数据结构

| 项目 | 内容 |
|------|------|
| **具体内容** | 数组、链表（单向/双向）、栈、队列（普通/优先/双端）、哈希表原理与实现 |
| **推荐资源** | 《算法图解》、LeetCode Hot 100 数组/链表专题 |
| **预计时间** | 2-3周 |
| **实践项目** | 用Python实现一个LRU缓存（Least Recently Used） |
| **验收标准** | 能手写链表反转、合并有序链表；LRU缓存通过10个以上边界测试用例 |

### 1.2 树与图

| 项目 | 内容 |
|------|------|
| **具体内容** | 二叉树（遍历/平衡树）、堆（优先队列）、哈希树、图（邻接表/矩阵）、BFS/DFS |
| **推荐资源** | 《算法导论》第12-23章、LeetCode 树与图专题 |
| **预计时间** | 3-4周 |
| **实践项目** | 实现一个文件搜索工具（DFS遍历目录树）+ 最短路径计算器（BFS/Dijkstra） |
| **验收标准** | 能实现二叉树层序遍历、验证二叉搜索树；文件搜索工具能正确处理符号链接和权限问题 |

### 1.3 排序与搜索算法

| 项目 | 内容 |
|------|------|
| **具体内容** | 快速排序、归并排序、堆排序、二分搜索、哈希搜索、跳表 |
| **推荐资源** | VisuAlgo 可视化平台、《算法导论》排序章节 |
| **预计时间** | 2周 |
| **实践项目** | 编写排序算法可视化对比工具（含时间/空间复杂度测试） |
| **验收标准** | 能分析各排序算法最好/最坏/平均时间复杂度；可视化工具能正确渲染排序过程 |

### 1.4 动态规划与贪心

| 项目 | 内容 |
|------|------|
| **具体内容** | 动态规划（状态定义/转移方程/空间优化）、贪心算法、分治法 |
| **推荐资源** | LeetCode 动态规划专题、labuladong算法小抄 |
| **预计时间** | 3-4周 |
| **实践项目** | 实现背包问题求解器 + 股票买卖最优策略计算器 |
| **验收标准** | 能独立解决Medium难度DP题目（如编辑距离、最长递增子序列）；贪心策略有正确性证明 |

## 二、数据库与网络

### 2.1 关系型数据库

| 项目 | 内容 |
|------|------|
| **具体内容** | MySQL/PostgreSQL安装与配置、SQL语法（DDL/DML/DQL）、索引原理与优化、事务ACID、锁机制 |
| **推荐资源** | 《MySQL必知必会》、MySQL官方文档、LeetCode SQL题库 |
| **预计时间** | 3-4周 |
| **实践项目** | 设计一个博客系统的数据库（含用户/文章/评论/标签多表关联），完成CRUD操作 |
| **验收标准** | 能手写复杂JOIN查询；理解覆盖索引与最左前缀原则；博客数据库通过ER图评审 |

### 2.2 网络编程

| 项目 | 内容 |
|------|------|
| **具体内容** | TCP/IP协议栈、HTTP/HTTPS协议、Socket编程、RESTful API设计 |
| **推荐资源** | 《图解HTTP》、《TCP/IP详解卷1》、MDN Web文档 |
| **预计时间** | 3周 |
| **实践项目** | 用Socket实现一个简单的HTTP服务器（支持GET/POST） |
| **验收标准** | 能解释TCP三次握手/四次挥手过程；HTTP服务器能正确处理并发请求（多线程/asyncio） |

## 三、工程化规范

### 3.1 项目架构与src布局

| 项目 | 内容 |
|------|------|
| **具体内容** | src布局实践、模块化设计、依赖注入、配置管理（.env）、日志系统（logging分级） |
| **推荐资源** | Python官方packaging文档、Real Python工程化系列文章 |
| **预计时间** | 2周 |
| **实践项目** | 将之前的博客系统重构为src布局，配置完整的日志和错误处理 |
| **验收标准** | 项目能通过pip install -e .安装；日志文件按级别分离输出；无硬编码敏感信息 |

### 3.2 测试与CI/CD

| 项目 | 内容 |
|------|------|
| **具体内容** | pytest框架、单元测试/集成测试、覆盖率统计（pytest-cov）、Mock测试、GitHub Actions流水线 |
| **推荐资源** | pytest官方文档、《Python单元测试》 |
| **预计时间** | 2-3周 |
| **实践项目** | 为博客系统编写单元测试（目标覆盖率>80%），配置GitHub Actions自动测试 |
| **验收标准** | 测试覆盖率>80%；CI流水线在push时自动运行测试并报告结果 |

### 3.3 代码质量工具链

| 项目 | 内容 |
|------|------|
| **具体内容** | ruff（lint/format/isort）、mypy类型检查、pre-commit钩子、代码审查流程 |
| **推荐资源** | ruff官方文档、mypy官方文档、pre-commit.com |
| **预计时间** | 1-2周 |
| **实践项目** | 配置完整的pre-commit钩子（ruff检查+mypy类型检查+测试运行） |
| **验收标准** | git commit时自动触发检查；mypy strict模式下无类型错误；代码格式化统一 |

## 四、方向深耕

### 4.1 Python后端开发

| 项目 | 内容 |
|------|------|
| **具体内容** | FastAPI/Django框架、ORM使用、API版本管理、认证授权（JWT/OAuth）、缓存策略（Redis） |
| **推荐资源** | FastAPI官方文档、Django官方教程、Redis官方文档 |
| **预计时间** | 4-6周 |
| **实践项目** | 开发一个完整的RESTful API服务（含用户认证、数据CRUD、Redis缓存、文档自动生成） |
| **验收标准** | API通过Swagger UI文档测试；JWT认证流程完整；关键接口响应时间<200ms |

### 4.2 容器化与部署

| 项目 | 内容 |
|------|------|
| **具体内容** | Docker基础与Dockerfile编写、Docker Compose多容器编排、Nginx反向代理、Linux服务器部署 |
| **推荐资源** | Docker官方教程、《Docker在实践中的使用》 |
| **预计时间** | 2-3周 |
| **实践项目** | 将博客API服务容器化，配置Docker Compose（含MySQL+Redis+API），部署到云服务器 |
| **验收标准** | docker-compose up即可启动完整环境；服务在云服务器上可通过域名访问 |
