# Vim 入门文档

Vim 是一个在终端里运行的模态编辑器：**不同模式下按键含义不同**，所以它不用鼠标、不用组合键，也能完成移动、删除、复制、替换。代价是有一段陡峭的适应期，收益是编辑操作可以像语言一样组合、在任意服务器上都能用。本文覆盖模式、移动、编辑、搜索替换、窗口、宏、配置与插件。

## 核心要点

- **模态编辑**：普通模式（移动与操作）→ 插入模式（打字）→ 可视模式（选中）→ 命令行模式（`:命令`）。
- **操作符 + 动作**：`d`（删除）、`c`（修改）、`y`（复制）后面接动作，如 `dw`、`ci"`、`y$`，可组合出成百上千种操作。
- **一切皆文本**：Vim 只认字符与行，不理解语法树；想要语义化跳转靠 LSP 插件。
- **可脚本化**：`.vimrc` 配置、宏、`:normal` 命令让重复劳动一次搞定。

## 一、模式与退出

启动与退出是所有新手的第一个坎：

```vim
vim file.txt      " 打开文件
:q                " 退出（无改动）
:q!               " 强制退出，丢弃改动
:w                " 保存
:wq  或  :x       " 保存并退出
```

| 模式 | 进入方式 | 用途 | 回到普通模式 |
| ---- | -------- | ---- | ------------ |
| 普通 Normal | 启动即是 / `Esc` | 移动、删除、复制 | — |
| 插入 Insert | `i` `a` `o` `I` `A` `O` | 输入文字 | `Esc` |
| 可视 Visual | `v` `V` `Ctrl+v` | 按字符 / 行 / 块选中 | `Esc` |
| 命令行 Command | `:` `/` `?` | 执行命令、搜索 | `Esc` |

插入模式的几个入口差别很关键：

| 按键 | 作用 |
| ---- | ---- |
| `i` / `a` | 在光标前 / 后插入 |
| `I` / `A` | 行首 / 行尾插入 |
| `o` / `O` | 下方 / 上方新开一行插入 |

> [!tip] 迷路时连按两下 `Esc` 回到普通模式；输入法在中文状态时，`:wq` 可能变成中文冒号，先切回英文。

## 二、移动

### 基本移动

```text
h j k l        左 下 上 右
w / b          下一个 / 上一个词首
e              词尾
0 / ^ / $      行首 / 首个非空字符 / 行尾
gg / G         文件开头 / 结尾
:<n>           跳到第 n 行，如 :42
Ctrl+d / Ctrl+u  向下 / 向上翻半屏
```

数字是乘数：`5j` 下移五行，`3w` 前进三个词，`10G` 跳到第 10 行。

### 按内容跳转

| 命令 | 作用 |
| ---- | ---- |
| `f<char>` / `F<char>` | 行内向后 / 向前跳到某字符 |
| `t<char>` / `T<char>` | 跳到某字符之前 |
| `%` | 在配对的括号间跳转 |
| `{` / `}` | 按空行分段跳转 |
| `Ctrl+o` / `Ctrl+i` | 跳回 / 前进到上一个位置（跳转表） |
| `m<char>` / `` `<char> `` | 打标记 / 跳回标记 |

## 三、编辑操作

### 删除、复制、粘贴

Vim 的删除其实是「剪切」，内容会进入寄存器，可以再粘贴。

| 命令 | 作用 |
| ---- | ---- |
| `x` | 删除光标处字符 |
| `dd` / `yy` / `p` | 删除整行 / 复制整行 / 粘贴到下方 |
| `D` / `C` / `Y` | 删到行尾 / 改到行尾 / 复制到行尾 |
| `dw` / `diw` | 删一个词 / 删光标所在词 |
| `d$` / `d0` | 删到行尾 / 删到行首 |
| `di"` / `ci(` | 删除引号内 / 修改括号内 |
| `>>` / `<<` | 增加 / 减少缩进 |

`d`、`c`、`y` 是操作符，接任何动作都能用：`dG` 删到文件末尾，`yap` 复制整段，`ciw` 改掉当前词。

### 撤销与重复

| 命令 | 作用 |
| ---- | ---- |
| `u` | 撤销 |
| `Ctrl+r` | 重做 |
| `.` | 重复上一次修改 |
| `n.` | 重复上一次修改 n 次（配合搜索极强） |

> [!tip] `.` 是 Vim 的效率核心：先设计好一次修改，再用 `n.` 批量重放。

### 可视模式

- `v` 按字符选择，`V` 按行选择，`Ctrl+v` 块选择（列编辑）。
- 选中后可直接 `d` / `y` / `c` / `>` 等操作。
- 块选择下 `I` 插入、`A` 追加，可以给多行同时加前缀或后缀，按 `Esc` 生效。

## 四、搜索与替换

```vim
/pattern          " 向下搜索，n / N 跳下一个 / 上一个
?pattern          " 向上搜索
*                 " 搜索光标下的词
:%s/old/new/g     " 全文替换
:%s/old/new/gc    " 全文替换，每次确认
:5,20s/old/new/g  " 第 5-20 行替换
:s/old/new/       " 仅当前行第一个匹配
```

| 参数 | 含义 |
| ---- | ---- |
| `g` | 一行内全部匹配（不加只替换第一个） |
| `c` | 每次替换前确认 |
| `%` | 整个文件范围 |
| `\v` | very magic 模式，正则里少写反斜杠，如 `:%s/\v(\w+)@(\w+)/\2@\1/g` |

`:noh` 取消搜索高亮，`:set hlsearch` 让它保持高亮。

## 五、窗口、标签页与文件

```vim
:sp file      " 水平分屏
:vsp file     " 垂直分屏
Ctrl+w h/j/k/l " 在窗口间移动
Ctrl+w =      " 等宽等高
:tabnew       " 新标签页
gt / gT       " 下一个 / 上一个标签页
:e file       " 打开另一个文件
:bn / :bp     " 下一个 / 上一个缓冲区
```

缓冲区（buffer）是打开的文件，窗口是它的视图，标签页是一组窗口的布局——三者不是一回事，习惯后可以同时编辑十几个文件而不混乱。

## 六、宏与寄存器

宏把一段按键录制下来重复播放：

```vim
qa        " 录制到寄存器 a
...操作...
q         " 停止录制
@a        " 播放一次
@@        " 重复上次播放
10@a      " 播放 10 次
```

寄存器前缀 `"`：`"ayy` 复制到 a 寄存器，`"ap` 粘贴。`"+y` / `"+p` 走系统剪贴板（需要 `+clipboard` 支持）。

> [!warning] `dd` 会覆盖无名寄存器。想反复粘贴同一段内容时，先粘到具名寄存器（`"0p` 可粘贴最近一次 yank）。

## 七、配置与插件

配置文件：Vim 用 `~/.vimrc`，Neovim 用 `~/.config/nvim/init.vim`（或 `init.lua`）。

```vim
set number            " 显示行号
set relativenumber    " 相对行号，配合 5j 更直观
set tabstop=4         " Tab 显示宽度
set shiftwidth=4      " 自动缩进宽度
set expandtab         " Tab 转空格
set ignorecase        " 搜索忽略大小写
set smartcase         " 有大写字母时区分大小写
set incsearch         " 边输入边搜索
set nowrap            " 不自动换行
syntax on             " 语法高亮
```

键位映射（`<leader>` 通常设为空格或逗号）：

```vim
let mapleader = " "
nnoremap <leader>w :w<CR>
nnoremap <leader>q :q<CR>
inoremap jk <Esc>
```

插件管理常用 [vim-plug](https://github.com/junegunn/vim-plug)：

```vim
call plug#begin()
Plug 'tpope/vim-surround'      " 快速增删改包围符号
Plug 'tpope/vim-commentary'    " gc 注释
Plug 'junegunn/fzf.vim'        " 模糊查找文件
Plug 'neoclide/coc.nvim'       " 补全与 LSP
call plug#end()
```

保存后执行 `:PlugInstall` 安装。Neovim 生态另有 lazy.nvim、telescope、nvim-treesitter 等，思路相同。

## 八、常见坑

| 现象 | 原因 | 建议 |
| ---- | ---- | ---- |
| 打开文件后打字乱跳 | 还在普通模式 | `i` 进入插入模式 |
| `:wq` 报错 | 中文输入法输出了中文冒号 | 切回英文再执行 |
| 粘贴代码缩进全乱 | 普通模式粘贴触发自动缩进 | 插入模式粘贴，或 `:set paste` / `"+p` |
| 想退出却卡住 | 有未保存改动 | `:q!` 丢弃，或 `:wq` 保存 |
| 高亮一直不消失 | 搜索高亮残留 | `:noh` |
| 配置不生效 | 改的是系统 vimrc 或路径不对 | 确认 `:echo $MYVIMRC` 指向的文件 |
| 方向键/退格异常 | 终端兼容问题 | 配置 `set nocompatible`、`set backspace=indent,eol,start` |

## 九、学习路线与练习

| 阶段 | 内容 | 练习 |
| ---- | ---- | ---- |
| 生存 | 模式切换、`i`/`Esc`、`:wq`、`:q!` | 用 Vim 改一个配置文件并保存 |
| 移动 | `hjkl`、`w`/`b`、`gg`/`G`、`f` | 在文件里只用键盘定位到指定行 |
| 编辑 | 操作符组合、`dd`/`yy`/`p`、`.` | 用 `ciw` + `n.` 批量重命名变量 |
| 进阶 | 搜索替换、可视块、宏 | 用宏把 100 行 CSV 转成 Markdown 表格 |
| 定制 | `.vimrc`、插件、LSP | 配一个能补全与跳转定义的编辑环境 |

> [!tip] 循序渐进：先禁用方向键和鼠标强迫自己用 `hjkl`，每天只学两三个命令，一周后速度会反超鼠标操作。
