### 标题

使用 `#` 号表示标题层级，`#` 后需加空格，支持 1-6 级标题：

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

---

### 文本样式

```
*斜体* 或 _斜体_        → 斜体
**粗体** 或 __粗体__    → 粗体
***粗斜体***            → 粗斜体
~~删除线~~              → 删除线
==高亮==                → 高亮（部分编辑器支持）
```

---

### 段落与换行

- 段落之间用**空一行**分隔
- 行内换行：在行尾加**两个空格**后回车，或使用 `<br>` 标签

---

### 列表

**无序列表**：使用 `-`、`+` 或 `*` 加空格

```
- 项目一
- 项目二
  - 嵌套项目
```

**有序列表**：使用数字加 `.` 和空格

```
1. 第一项
2. 第二项
```

**任务列表**：

```
- [ ] 未完成任务
- [x] 已完成任务
```

---

### 引用

使用 `>` 符号，支持多级嵌套：

```
> 这是一段引用
>> 嵌套引用
```

---

### 代码

**行内代码**：使用单反引号 包裹

```
使用 `print()` 函数输出内容
```

**代码块**：使用三个反引号 包裹，可指定语言实现语法高亮：

````
```python
def hello():
    print("Hello, World!")

```
````

---

### 链接与图片

```
[链接文字](https://www.example.com "可选标题")
![替代文字](图片URL "可选标题")
```

---

### 表格

使用 `|` 分隔列，`-` 分隔表头与内容，通过 `:` 控制对齐：

```

| 左对齐 | 居中对齐 | 右对齐 |
| :----- | :------: | -----: |
| 单元格 | 单元格   | 单元格 |
```

---

### 分割线

使用三个或以上的 `-`、`*` 或 `_`：

```
---
***
___
```

---

### 转义字符

在特殊符号前加反斜杠 `\` 进行转义：

```
\*这不是斜体\*
\# 这不是标题
```

---

### 脚注

```
这是一段带脚注的文字[^1]

[^1]: 这是脚注内容
```

---

### 进阶功能

- **数学公式**：`$...$` 行内公式，`$$...$$` 块级公式
- **Mermaid 图表**：支持绘制流程图、时序图、甘特图等
- **HTML 混编**：支持嵌入 HTML 标签实现更丰富的样式
