# Obsidian 快捷键

Obsidian 提供了一套默认键盘快捷键，并允许在「设置 → 快捷键（Hotkeys）」中为任意命令自定义按键。掌握少数几个高频快捷键，就能显著提升记笔记的效率。

## 核心要点

- 最高频的两个入口：**命令面板** `Ctrl/Cmd + P` 与 **快速切换器** `Ctrl/Cmd + O`。
- 命令面板里会直接列出每条命令已绑定的快捷键，是查询快捷键最快的方式。
- 默认只绑定了一部分常用命令；侧边栏、分屏、折叠等许多命令默认未绑定，可按需自行设置。
- 下表为 Obsidian 默认值，Windows/Linux 与 macOS 分列。

## 常用快捷键

### 导航与查找

| 功能 | Windows / Linux | macOS |
| ---- | --------------- | ----- |
| 命令面板 | `Ctrl + P` | `Cmd + P` |
| 快速切换器（打开笔记） | `Ctrl + O` | `Cmd + O` |
| 在当前文件中搜索 | `Ctrl + F` | `Cmd + F` |
| 在当前文件中搜索并替换 | `Ctrl + H` | `Cmd + H` |
| 在所有文件中搜索 | `Ctrl + Shift + F` | `Shift + Cmd + F` |
| 打开关系图谱 | `Ctrl + G` | `Cmd + G` |
| 后退 / 前进 | `Ctrl + Alt + ←/→` | `Alt + Cmd + ←/→` |
| 跟随光标下的链接 | `Alt + Enter` | `Alt + Enter` |
| 在新窗格打开光标下的链接 | `Ctrl + Alt + Enter` | `Alt + Cmd + Enter` |
| 打开设置 | `Ctrl + ,` | `Cmd + ,` |
| 打开帮助 | `F1` | `F1` |

### 文件与窗格

| 功能 | Windows / Linux | macOS |
| ---- | --------------- | ----- |
| 新建笔记 | `Ctrl + N` | `Cmd + N` |
| 关闭当前窗格 | `Ctrl + W` | `Cmd + W` |
| 保存文件 | `Ctrl + S` | `Cmd + S` |

### 编辑

| 功能 | Windows / Linux | macOS |
| ---- | --------------- | ----- |
| 加粗 | `Ctrl + B` | `Cmd + B` |
| 斜体 | `Ctrl + I` | `Cmd + I` |
| 插入链接 | `Ctrl + K` | `Cmd + K` |
| 删除当前段落 | `Ctrl + D` | `Cmd + D` |
| 切换编辑 / 阅读视图 | `Ctrl + E` | `Cmd + E` |

### 编辑器内置操作

以下属于编辑器行为，不在快捷键设置列表中：

- 输入 `[[`：触发库内笔记的链接自动补全。
- `Tab` / `Shift + Tab`：缩进 / 反缩进列表项。
- `Ctrl + 单击`（macOS `Cmd + 单击`）：在新标签页中打开链接。

## 自定义快捷键

1. 打开「设置 → 快捷键（Hotkeys）」。
2. 搜索命令名（中英文皆可）。
3. 点击命令右侧的 `+` 并按下想要的组合键即可绑定；点击垃圾桶图标可解除绑定。
4. 若组合键已被占用，Obsidian 会给出冲突提示。
5. 也可以在命令面板中直接查看某条命令当前绑定的按键。
